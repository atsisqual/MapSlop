# PortoSlop — public-client investigation (2026-11-27)

Scope: read-only public interface and developer statements, to inform independent MapSlop development. This is a functional investigation, NOT a completed source-level reverse engineering. No third-party code or assets imported.

## Evidence
- https://porto.tremocogames.com/ — game page successfully retrieved through a text/HTML extraction service; extraction strips script elements. On-page controls describe walking and driving (WASD/arrows), sprint/nitro, entry/exit of cars, handbrake, horn, third-person/mouse camera, minimap, taxi, chat, unified aircraft controls and police/wanted/jail gameplay. The site advertises mobile touch controls and home-screen installation, but manifest/service worker not verified.
- https://porto.tremocogames.com/editor.html — publicly linked map editor. The read-only page extraction shows name, type, game notes, direction, height, length, width, zone radius, reference photos and placement of markers. The editor currently displays Ferreira branding despite Porto hostname. Shared engine/configuration is a hypothesis, not proof.
- https://porto.tremocogames.com/tickets.html — publicly linked feedback system, also labelled FerreiraSlop. Describes AI-assisted implementation of feature requests. No submissions or edits performed.
- https://www.reddit.com/r/aigamedev/comments/1y5jcde/portoslop_the_gta_we_deserve_but_in_porto/ — author statement retrieved: Claude Opus 5.5, roughly five days of iterations, OpenStreetMap, procedural/low-poly Porto-style buildings, selected monuments modeled in Three.js using real photographs, approximately 27 km². Advertised multiplayer, mobile, characters, jobs/economy, tuning, aircraft/boats and building destruction. Author claims, not independently tested.

## MapSlop implications
P0: keyboard/gamepad driving, handbrake, third-person chase camera, free movement off-road, collisions and real OSM roads/terrain; select an MIT upstream after tests. P1: walk/enter/exit, mobile controls, minimap, traffic. P2: configurable taxi/jobs/economy/police and persistent vehicle customization. P3: independent location editor using map coordinates, dimensions, category, notes and licensed reference imagery; export map-specific configuration; no coupling to runtime vehicle mechanics. Later: aircraft/boats, destruction, multiplayer. Reuse the existing licensed Slop family and other projects documented in reuse-audit.md rather than copying unlicensed PortoSlop code.

## What is still unknown
Exact client script URLs and source maps, Three.js version/render backend, physics engine, road meshing algorithm, elevation source, map formats, vehicle equations, server authority/protocol, upstream provenance and code/asset licenses. The container could not resolve the site; standard web fetch failed; browser automation could not start because of provider balance. The text extraction service returned cleaned HTML only. No JS bundle or actual network trace obtained, no source comparison executed, no gameplay tested. Do not claim a verified engine match. Capture a sanitized browser HAR of public static resources plus page source, ideally game and editor separately, or request source/permission from author. Exclude credentials, tokens, player/chat data and private responses; do not publish captured third-party code in MapSlop.
